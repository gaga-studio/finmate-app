# FinMate 화면 연결 검증

## 2026-10-03: 기존 더보기·기록 탭 API 연결

- 폰 프레임·다섯 탭·카드 배치를 유지했습니다. 피드의 기존 더보기에 소득대 평균을, 기록의 월 이동·날짜 카드에 월별 요약·전체 거래를 연결했습니다.
- Playwright 16개 통과: 시연 모드 4개, API 모드 12개. 데스크톱과 모바일에서 같은 흐름을 확인했습니다.
- 실제 로컬 API와 PostgreSQL에서 6월 내 소비 72,600원, 같은 소득대 평균 187,600원, 인원 24명, 6월 30일 데모 저녁 12,000원을 화면과 대조했습니다.
- 미적재 8월을 0원으로 바꾸지 않는지, 503 후 재시도, dialog의 Escape와 이전 버튼으로 초점 복원을 확인했습니다.
- 거래 페이지 경계는 별도의 HTTP 응답 대역 21건으로 확인했습니다. 두 번째 페이지 실패 시 합계를 숨기고, 재시도 후 21건과 무거래일을 구분합니다. 실제 데모 DB의 거래 수를 늘린 실험은 아닙니다.
- 월간 API는 월초부터 기준일까지입니다. 과거 월은 말일을 요청하며 기준 월은 서버 기준일까지 조회합니다. 6월 1일만 요청해 월 지출을 0원으로 표시하던 구현 중 오류를 회귀 검사로 수정했습니다.
- TypeScript·Vite 빌드 통과, lint 오류 0. 기존 Fast Refresh 경고 11개와 큰 번들 경고는 남아 있습니다.
- 그림·스토리·프로필·분석·미션 등은 시연 자료입니다. 실제 은행 API, 실제 AI, 공개 백엔드 배포를 검증했다는 뜻이 아닙니다.

## 확인한 범위

- 화면 기준은 `494750b`의 팀 시연 UI입니다. 라우터와 앱 진입점을 복원하고 추가 대시보드를 제거했습니다.
- 기준 커밋과 비교해 폰 프레임·다섯 탭·각 페이지·차트·이미지·스타일은 동일합니다. API 클라이언트·데이터 공급 계층과 예산 카드·소비 목록의 오류·빈 상태 처리는 보강했습니다.
- 같은 뷰포트에서 기준 화면과 수정 화면의 다섯 탭을 촬영했습니다. 데스크톱 1440×1050, 모바일 390×844이며 실제 레이아웃을 대조했습니다. 반복 애니메이션이 있는 화면은 촬영 시점에 따라 일부 픽셀이 달라질 수 있습니다.
- Playwright **10개 통과**: 시연 모드의 탭 이동·기간 전환·소비/저축/투자·공유 카드, 서버 모드의 실제 예산/소비 탑 5·503 오류 후 재시도·자료 없음. 데스크톱과 모바일에서 실행했습니다.
- 서버 시험은 실행 중인 로컬 FinMate API와 PostgreSQL의 합성 데이터를 사용했습니다. 503 시험은 실패 응답만 주입합니다. 자료 없음 시험은 요청 날짜를 미적재 날짜로 바꾸어 실제 서버 응답을 확인합니다.
- 임의 날짜 요약·전체 거래·또래 비교는 API 요청으로 검증했습니다. 원래 화면에서 이 기능들을 선택했다는 뜻이 아닙니다.
- `npm run lint` 오류 0. 기존 Fast Refresh 파일 구성 경고가 남아 있습니다. TypeScript·Vite 빌드는 통과했으며 기존 큰 번들 경고가 남아 있습니다.
