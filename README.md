# FinMate

> 금융이 막막한 20대의 첫 금융 온보딩 서비스

20대는 금융관리가 필요하다는 걸 안다. 그런데 시작하지 못한다.
FinMate는 정보를 더 주는 대신, **또래를 구경하다가 오늘 할 수 있는 작은 행동 하나로 넘어가게** 만든다.

하나금융그룹 × 금융감독원 **2026 청년 금융인재** 프로젝트에서 4인 팀(가가제작소)으로 만들었다.
이 저장소는 그중 **모바일 웹앱**이다. → [finmate-api](https://github.com/gaga-studio/finmate-api) · [finmate-data](https://github.com/gaga-studio/finmate-data)

---

## 1. 문제 — 아는 것과 하는 것 사이의 거리

20대의 금융이해력은 내려가는데 부채는 폭증하고 있다.

| | 2022 | 2024 | |
|---|---:|---:|---|
| 종합 금융이해력 | 66.5 | 65.7 | ▼ 0.8 |
| 금융지식 | 75.5 | 73.6 | ▼ 1.9 |
| 금융행위 | 65.8 | 64.7 | ▼ 1.1 |
| 금융태도 | 52.4 | 53.7 | ▲ 1.3 |

<sub>한국은행·금융감독원, 「2024 전국민 금융이해력 조사」</sub>

같은 기간 가계부채 증가율은 전체 **+51.8%**, 30대 **+115.3%**, 그리고 **20대 +217.9%**였다.
<sub>통계청·한국은행·금융감독원, 「가계금융복지조사」(2014–2023)</sub>

20대 97명에게 직접 물었더니 갈라진 지점이 보였다 — 금융관리가 **필요하다고 답한 비율은 78%**인데,
실행을 미루는 이유의 1·2위는 *"어렵고 귀찮아서"*와 *"무엇부터 해야 할지 몰라서"*였다.

> **필요한 건 더 많은 정보가 아니라, 마찰 없이 시작할 수 있는 첫 걸음이다.**

## 2. 가설 — 무엇이 20대를 실제로 움직이는가

설계 전에 두 가지를 정하고, 20대 108명에게 홈 화면을 보여주며 검증했다.

| | 가설 | 근거로 삼은 관찰 |
|---|---|---|
| **1** | 또래의 금융 행동을 보여주면 동기가 생기고, 실행에 대한 심리적 저항이 줄어든다 | *"다들 청약통장 있었어? 나만 없네"* — 나만 안 하고 있었다는 자각의 순간 |
| **2** | 작은 미션을 주면 "무엇부터 해야 할지 몰라서" 못 시작하는 문제가 풀린다 | 미루는 이유 2위가 곧 진입 장벽 |

또래 비교라는 방향 자체는 하나금융그룹이 이미 핀크 **리얼리**로 운영하고 있어, 수요가 아니라 **대상(20대)과 진입점(미션)**을 다르게 잡는 문제로 좁혔다.

## 3. 해법 — 구경에서 실행까지 한 화면 안에서

두 가설을 그대로 두 개의 흐름으로 옮겼다.

**또래 스토리** — 구경이 동기가 된다
```
그룹으로 찾기 → 금융 스토리로 발견 → 비교·AI 분석으로 연결
```
소득·소비·지역이 비슷한 또래를 찾고, 그들의 소비·저축·투자를 짧은 카드로 본다. 금융관리를 부담이 아니라 일상 콘텐츠로 만든다.

**AI 코치 미션** — 막막함이 할 일이 된다
```
고민 입력 → 맞춤 플랜 제안 → 미션으로 수행
```
"돈을 모으고 싶다" 같은 생활 언어를 넣으면, 지금 할 수 있는 크기의 행동으로 잘라 준다.

### 화면

| 탭 | 무엇을 하는가 |
|---|---|
| **마이** | 오늘의 예산(물잔)·저축 목표(링)·투자(라인)를 가로 스와이프로 전환. 위로 밀거나 기간 칩을 누르면 **일간/주간/월간으로 화면 전체가 갈아입는다** |
| **피드** | 또래 그룹 찾기(소득·소비·지역·팔로잉) + 오늘의 금융 스토리 12장 |
| **미션** | 포인트·상점, "예산을 지켜라" 챌린지, 해체분석 근거가 붙은 추천 미션 |
| **다이어리** | 하루의 소비를 AI 그림 한 장으로. 과거는 일별 수입/지출 타일 |
| **인사이트** | 습관 기반 **미래 6개월 투영** 그래프 위에 메이트를 겹쳐 비교. 슬라이더·퀴즈·리포트 생성 |

**Wrapped 공유 카드** — 아트 카드를 누르면 9:16 풀스크린으로 확대되고, 1080×1920 PNG로 저장·공유된다. 혼자 보는 지표를 남에게 보여줄 수 있는 형태로 바꾸는 자리다.

### 데이터

앱의 모든 숫자는 **거래 원장에서 파생**된다. 기간을 바꿔도 숫자가 어긋날 수 없는 구조다(`src/data/selectors.ts` 한 곳에서 집계).

원장 자체는 카드 이용 데이터 EDA로 만든 합성 데이터다 — 실측 분위·업종 구성비·상관을 뽑아 가상 사용자를 만들고, 마이데이터 표준 API 형태로 앱에 넣었다. <sub>(이 EDA·데이터 생성은 팀의 데이터 담당이 [finmate-data](https://github.com/gaga-studio/finmate-data)에서 진행했다)</sub>

### 두 가지 실행 모드

| | 조건 | 데이터 |
|---|---|---|
| **목 모드** (기본) | `VITE_API_URL` 없음 | 고정 시드 — 어느 날 실행해도 화면이 같다 |
| **서버 모드** | `VITE_API_URL` 설정 | finmate-api의 실제 원장 |

```bash
npm install
npm run dev                                      # 목
VITE_API_URL=http://localhost:8080 npm run dev   # 서버
```

목 모드를 남긴 이유는 **시연 영상 촬영 재현성**이다. 앱의 "오늘"은 항상 2026-07-18로 고정하고(`new Date()` 직접 호출 금지), 시연 대사에 나오는 거래는 수기로 박아 뒀다. 어느 모드인지는 `src/data/source.tsx` 한 곳이 정하고 컴포넌트는 알 필요가 없다.

모바일 뷰포트(390×844) 기준이며, 데스크톱에서는 430px 폰 프레임으로 렌더된다.

### 기술

| 영역 | 선택 |
|---|---|
| 빌드·UI | Vite · React 19 · TypeScript strict |
| 스타일 | Tailwind CSS v4 (`@theme` 토큰, config 파일 없음) |
| 모션 | Motion v12 — 스프링 프리셋 3종(`snappy`/`gentle`/`dramatic`)으로 톤 통일 |
| 라우팅 | React Router 7 (Wrapped 오버레이는 라우트가 아닌 `?card=`) |
| 차트 | **라이브러리 없음** — 커스텀 SVG + Motion. 물잔은 사인파 2장의 수평 루프다 |
| 데이터 | 정적 TS 모듈 + 순수 셀렉터. 상태관리 라이브러리 없음 |
| 캡처 | html-to-image (폰트 셀프호스팅 + iOS 2회 호출 워크어라운드) |

## 4. 남기려는 것 — 한 번 쓰고 마는 앱이 아니라

```
① 초기 유입          ② 리텐션              ③ 성장 루프
타인에 대한 궁금증  →  미션과 데일리 관리  →  쌓인 실행 데이터가
로 들어오고           로 습관이 되고        더 좋은 추천이 되어 다시 부른다
```

고객은 첫 금융 행동을 만들고, 하나금융그룹은 포용금융을 실현하며 그 실행 데이터를 얻는다.
FinMate는 **첫 월급부터 내 집 마련까지, 인생의 금융 순간마다 함께하는 서비스**로 확장하는 것을 목표로 한다.
